# W01 · Project, schema và catalog Việt Nam

**Phụ thuộc:** W00. **Entry:** Mở mẫu → chọn thiết bị → nhân bản → sửa → lưu → mở lại.

- W01.1 Tạo schemas/project-v1.json, component-v1.json, offer-v1.json, schema loader và parser đơn vị. Chọn chuẩn lưu V/A/W/Wh/m, hệ số theo phần số; UI hỗ trợ dấu phẩy thập phân tiếng Việt. Reject NaN, âm vô lý, chuỗi rỗng, điện áp đảo min/max, tham chiếu hỏng.
- W01.2 Tạo data/catalog và bộ lọc panel/inverter/battery/controller/load. Biên tập tối thiểu hai model tấm có đủ thông số, một inverter, một pin có datasheet, một pin cũ tự nhập, một controller/bơm mẫu. Họ sản phẩm chưa rõ biến thể vẫn xuất hiện với khả năng kiểm tra ghi cụ thể.
- W01.3 Implement ProjectRepository trên IndexedDB, ID độc lập cho model/revision/offer/instance; import/export JSON cơ bản, clone project và diff revision. Viết form “tạo thiết bị từ đầu” và “sao chép thiết bị có sẵn”.
- **Nghiệm thu:** sửa Ah trên bản clone giữ dữ liệu gốc; hai báo giá cho cùng SKU chỉ sinh một technical revision; reload offline giữ draft; import sai đơn vị báo đúng trường và giữ draft. Evidence gồm schema, hai snapshot và round-trip test.
