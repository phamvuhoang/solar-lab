# W03 · Editor 2D và kiểm tra điện

**Phụ thuộc:** W01, W02. **Entry:** Thiết kế → thêm theo lô → nối từng string vào MPPT → bấm lỗi để sửa.

- W03.1 Tạo src/domain/graph.ts, src/validation/strings.ts và diagrams/editor. Tách tọa độ màn hình khỏi connectivity. Tạo preset 1 chuỗi, 2 chuỗi cùng tracker và 2 tracker độc lập; thêm nhánh tải AC, pin/bus và controller bơm riêng. Thao tác nối/xóa/undo cập nhật BOM.
- W03.2 Implement lỗi sai loại cổng, trùng panel trong hai nguồn, vượt điện áp hở mạch lạnh, thiếu điện áp MPPT nóng, quá Isc và vượt dòng vận hành. Từng rule ghi source fields, công thức, giá trị và hậu quả. Thông số thiếu trả unknown.
- W03.3 Tạo badge riêng “đủ dữ liệu”, “bị giới hạn công suất”, “vượt giới hạn thiết kế”; chọn một issue focus đúng thiết bị/cổng. Cung cấp form chỉnh kết nối bằng bàn phím tương đương kéo thả.
- **Nghiệm thu:** fixture tấm Voc=50 V, βVoc=−0,25%/°C, nhiệt độ cell thấp nhất −5°C, Ns=8 → Voc lạnh 430 V. Giới hạn 420 V phải báo lỗi, 450 V qua phép so Voc. Hai string có Isc=14 A mỗi string trên cùng tracker 25 A làm fail kiểm tổng Isc; chia sang hai tracker 25 A thì qua riêng kiểm đó. Giá và BOM giữ nguyên khi chỉ chuyển cổng.
