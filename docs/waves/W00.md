# W00 · Khởi tạo codebase độc lập

**Đầu vào:** thư mục seed (tài liệu thiết kế, `src/cost/bom.ts`, `tsconfig.base.json`, test BOM). **Đầu ra:** trang khởi động Solar có preset Lâm Hà, một lệnh dev, một lệnh build.

- W00.1 Chạy bộ test BOM và ghi kết quả vào evidence. Soát danh sách file trong project mới; seed dùng địa chỉ tương đối trong chính thư mục Solar.
- W00.2 Thêm Vite, TypeScript, Vitest, Playwright vào package root; tạo lockfile pnpm, tsconfig con, index.html và src/main.ts. UI bước này chỉ cần “Tạo dự án” và “Mở mẫu Lâm Hà” dẫn tới bản thiết kế nháp có tên.
- W00.3 Tạo CI từ checkout sạch: install --frozen-lockfile, typecheck, unit, build, E2E shell. Xin port riêng/port trống khi chạy local; kiểm network trong browser test để phát hiện request ngoài dự kiến.
- **Nghiệm thu:** checkout sạch, đứng riêng, chạy được; CI bắt import ra ngoài thư mục dự án và đường dẫn tuyệt đối. Chụp build metadata và hash fixture. BOM và smoke test là phần đã có trong seed; Vite, lockfile và CI là đầu việc còn lại.
